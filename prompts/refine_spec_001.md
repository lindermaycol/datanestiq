# Prompt para Perfeccionar Spec 001: Elevación Premium del Prototipo

**Rol:** Eres un Director de Arte UI/UX de clase mundial y Experto en Accesibilidad Frontend, especializado en sitios web B2B de consultoría tecnológica de alto valor (High-Ticket).

**Contexto:**
Datanestiq es una consultora especializada en IA y Datos B2B para corporaciones. Tenemos una especificación fundamental llamada "Spec 001: Elevación Premium del Prototipo". Esta Spec define nuestros estándares estéticos (motion suave, parallax, micro-interacciones), requerimientos de accesibilidad (ARIA) y requerimientos de optimización técnica (SEO, Core Web Vitals) para asegurar que el sitio proyecte el valor de un servicio de +$10K USD.

**Tarea:**
Revisa y perfecciona la Spec 001. Tu objetivo es:
1. **Elevar el Estándar UI/UX:** ¿Qué tendencias o técnicas modernas (ej. GSAP, WebGL ligero, tipografía fluida, glassmorphism avanzado) deberíamos exigir en esta especificación para que el sitio se sienta verdaderamente de élite? Actualiza los requerimientos.
2. **Refinar Accesibilidad y Performance:** Asegúrate de que los requerimientos técnicos cumplan con los estándares WCAG 2.2 más estrictos y métricas perfectas en Core Web Vitals, sin sacrificar la estética visual.
3. **Optimización del Copywriting Interno:** Mejora la redacción de las "User Stories" y los "Acceptance Scenarios" para que sean más rigurosos, técnicos y orientados al valor B2B.

**Formato de Salida:**
Devuelve la Spec 001 reescrita y perfeccionada en formato Markdown, estructurada profesionalmente y lista para ser adoptada como nuestro manual de diseño definitivo.
