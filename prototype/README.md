# Prototipo Histórico Datanestiq (Vanilla JS/HTML/CSS)

Este directorio contiene la versión original y fundacional del prototipo de Datanestiq antes de su migración a la arquitectura moderna (Astro + React + Tailwind + WordPress Headless).

## Motivo de Preservación
Esta carpeta no se despliega en producción, pero se mantiene intacta en el repositorio como:
1. **Referencia Histórica:** Documenta las primeras pruebas de concepto de microexperiencias de IA, el Chatbot y el UI.
2. **Backups de Lógica:** Contiene lógicas originales (ej. `app.js` Vanilla) que pueden servir de referencia rápida si un componente de React/Astro en el nuevo ecosistema experimenta una regresión.
3. **Auditoría:** Permite a los agentes y desarrolladores validar los requerimientos fundacionales y el "look and feel" inicial aprobado por el directorio.

**Por favor NO modificar los archivos en esta carpeta**. Todo nuevo desarrollo se debe realizar en el directorio raíz (Astro) o en la instancia de WordPress.
